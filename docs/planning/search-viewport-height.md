# התאמת גובה החיפוש למסך הקיים

## היקף מאושר
שינוי ממוקד באתר הקיים כדי להציג את כפתור החיפוש ללא גלילה ככל שהפריסה מאפשרת. המשתמש הבהיר ש־50% מגובה החלון היו דוגמה, ולא מגבלה קשיחה. ההתאמה תהיה באמצעות CSS בלבד, ללא מדידת תוכן, zoom, הוספת גלילה פנימית או מדיה־קוואריז חדשים. אין מימוש של הצעת שני המסכים במסגרת השינוי הזה.

## ביצוע
- להסיר את מדידת הגודל, ResizeObserver, מאזיני שינוי הגודל ו־CSS zoom שהוכנו קודם.
- להתאים את משתני הריווח והטיפוגרפיה של Tailwind בתוך אזור החיפוש באמצעות clamp ויחידות dvh. הריווח קטן בחלונות נמוכים, עם ערכי מינימום לטקסט.
- לשמור על מרווח עליון שמתחשב בסרגל הניווט הקבוע.
- להציג ספר ונושא בשתי עמודות גם במסכים צרים, ואת קבוצות המקור בשתי עמודות, כדי להימנע מערימה אנכית מיותרת. פריסת ארבע העמודות במחשב נשארת כפי שהיא.
- לא להוסיף חיתוך תוכן או אזור גלילה חדש. רשימות הבחירה הקיימות אינן משתנות.
- להשאיר את התוצאות בגודל הרגיל ולהחיל את ההתאמה רק על אזור הכותרת והחיפוש.
- לא לשנות את useSearch, הידרציה, הרשאות או בקשות API.

## מגבלות
התאמה רספונסיבית ללא מדידה אינה מבטיחה שכל כמות שרירותית של שורות סינון תיכנס לכל גובה חלון. בחלון נמוך במיוחד או עם מקורות רבים העמוד יכול לגדול; התוכן אינו נחתך ואינו מוקטן מתחת לערכי המינימום שנקבעו. אין לקבוע שהכפתור נבדק בכל גודל מסך ללא בדיקת דפדפן.
