# סיפור השבוע: שימוש בנתיב סיפורי הדוגמה

סטטוס ארכיון — 2026-11-11: המימוש קיים ומפרט המצב כבר מתאר אותו. הסתירה הישנה במפרט נסגרה; ההחלטה על קישור קבוע לשיתוף נשארת ב־[backlog](../backlog.md).

## מה מומש ולמה

הפעולה ״מעבר לתשובה״ ב־[VideoSection](../../../app/_components/video-section.tsx) מקשרת ל־`/story/featured/${weeklyStory.id}`. ה־[FeaturedStoryView](../../../app/story/featured/%5Bid%5D/_components/featured-story-view.tsx) פותר את המזהה מתוך `featuredStories` או `weeklyStory` שב־`useAppDataStore`.

כך סיפור השבוע זמין ללא התחברות דרך נתיב סיפורי הדוגמה הקיים, בלי עמוד נוסף. הקישור תלוי בסיפורים שבחבילת נתוני האפליקציה הנוכחית; אין בו טעינת סיפור קבועה לפי מזהה מהשרת. אם הסיפור אינו נמצא, מוצג מצב ריק.

## סגירת התיעוד

[מפרט המצב והמטמון](../../specs/03-stores-and-cache.md#featured-and-weekly-routes) מתאר את הנתיב ואת המגבלה. דרישת שכפול הנחיות ל־CLAUDE.md מהמסמך המקורי בוטלה בתהליך פישוט התיעוד; המפרטים הם המקור המתוחזק.

הארכוב אינו משנה את הנתיב ואינו מכריע אם סיפור השבוע צריך להישאר זמין בקישור קבוע לאחר החלפתו.
