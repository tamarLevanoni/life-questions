# תוכניות עבודה

תוכניות אינן הנחיות מחייבות לסוכן. [המפרטים](../specs/README.md) מתארים את הפרויקט המתוחזק. `done/` מכילה היסטוריה ויכולה להזכיר קוד שכבר הוחלף.

| מסמך | מצב | שימוש |
|---|---|---|
| [תשתית איכות](project-quality-foundation.md) | פעיל | תיעוד, סקילים, אבטחה ובדיקות; מקור המעקב לעבודה זו |
| [חיפוש ותוצאות בשני מסכים](search-results-screens.md) | הצעה, לא מאושרת למימוש | חלופה עתידית לעיצוב החיפוש |
| [סיפור שבועי ושיתוף](weekly-story-shareable-link.md) | מימוש קיים; החלטת מוצר פתוחה | אין שינוי ניתוב במסגרת ניקוי |
| [Backlog](backlog.md) | עבודה עתידית | שאלות ויעדים שאינם חוזה קיים |

## ארכיון

[תוכניות היסטוריות](done/) נשמרות לעיון בלבד. הן עשויות לתאר קוד שהוחלף ואינן מעידות שהבדיקות המתוארות בהן עדיין קיימות. להחלטות פעילות השתמשי במפרטים וב־backlog.
