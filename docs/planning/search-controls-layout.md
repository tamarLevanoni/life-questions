# סידור אזור החיפוש

## מטרה
להציג חיפוש חופשי, אחריו חיפוש לפי קטגוריות ולבסוף כפתור חיפוש. שדה הטקסט והכפתור נשארים גלויים גם כאשר הקטגוריות מצומצמות.

## ביצוע
- להעביר את החיפוש החופשי ואת כפתור החיפוש מ־`CategoryFilterBar` אל `SearchFiltersPanel`, מחוץ לאזור המתקפל.
- להשאיר ב־`CategoryFilterBar` רק את בקרי הקטגוריות; ניקוי קטגוריות ישמור על הטקסט החופשי.
- לנהל את פתיחת הקטגוריות ב־`useSearch` ולצמצם אותן בכל חיפוש מורשה, כולל חיפוש מפרמטרים בכתובת. לאפשר פתיחה ידנית לשינוי הסינון.
- לשמור על הפעלת חיפוש באמצעות Enter ועל הסינון הקיים, בלי לשנות את מסלול בקשות החיפוש.

## אימות
- `bunx tsc --noEmit` עבר.
- בדיקת רינדור עם `renderToStaticMarkup` עברה בשני המצבים: סדר הבקרים נשמר, הטקסט והכפתור קיימים תמיד ותוכן הקטגוריות מוצג רק במצב פתוח.
- `bun lint` נכשל בטעינת כלל `react/display-name` בקובצי `_boilerplate-reference`, עקב שגיאת תאימות בכלי: `contextOrFilename.getFilename is not a function`.
